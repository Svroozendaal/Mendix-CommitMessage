# ACM AI Skills

## Purpose

`AI-tools/skills/` stores app-specific skills used by agents working with ACM and Mendix model changes.

## Skill Map

- `acm-parser-usage/` explains how to run the ACM parser end to end and where outputs land.
- `mendix-model-dump-inspection/` explains how to inspect dump JSON and maintain deterministic parser rules.
- `mendix-technical-commit-message/` converts module-grouped export data into technical commit-message lines.
- `mendix-commit-structuring/` defines how Mendix model changes should be structured for commit-message generation.
- `mendix-sdk/` contains Mendix SDK usage knowledge.
- `mendix-studio-pro-10/` contains Studio Pro 10 extension/platform constraints.
- `write-technical-commit/` contains writing guidance for technical commit output.
- `mendix-model-overview-export/` is present as a skill folder and should be checked before editing overview/export guidance.

## Maintenance Notes

- `OVERVIEW.md` is the directory index and should be updated when skill folders are added or renamed.
- Skill references under `references/` are rule libraries; treat them as part of the skill contract.
- Keep skill instructions consistent with MCP tool names and parser export fields.
